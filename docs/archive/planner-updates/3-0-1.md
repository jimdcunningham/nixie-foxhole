## General Changes
- Added Community Blueprints:
    - Upload, search, and subscribe to blueprints created by the community.
    - Replaces the old "Presets" system. (Modules, Showcase, etc.)
    - Previous links to presets redirect to the new blueprint system.
- Added Hotbar Menu:
    - Project, Overlay, and Map panels are now separate tabs in the hotbar.
    - Added buttons for toggling pop-out panels on the board to the hotbar.
        - (eg. Statistics, Toolbelt)
    - Added buttons for accessing blueprints, library, logging in/out, and user settings.
- Hub home has been updated with a featured banner and new UI for the buttons.
- Moved Project Settings to a dedicated Project page within the hub.
- Project page now has blueprint options for uploading your blueprint and managing it.
- Added a variety of new options to the menubar, including a new Blueprint dropdown.
- Added new Library page to the hub that lists all of your locally stored projects.
- Added buttons to set a custom avatar and display name for your account.
- Added a new dedicated popout screenshot dialog.
- Added paste option to context menus. (Unsupported in Firefox)
- Added expand / contract options for categories to "View" menu in Assets browser.
- Reimplemented setting to show / hide collapsible categories in Assets browser.
- Added an icon to exported projects that displays when imported into another project.
- Added advanced project setting for excluding layers when exporting the project.
- Added confirmation dialogs for creating new layers, folders, and tilesets.
- Board grid now updates to visually match the size in settings and scales with the camera.
- Added zoom percentage and grid size buttons to the footer bar.
- Lowered max grid size to 128x128 pixels.
- Updated all hub pages and confirmation dialogs with new UI.
- Combined account and settings pages in the hub.
- Controls page has been updated to include rebinding and more hotkeys that were previously missing.
- Changelogs now appear as tagged resource pages in the new Resources tab in the hub.
- Fixed screenshots and project icons not taking layers into account.
- Browser / OS scaling now affects the canvas alongside the UI. Supporting HiDPI displays.
- Updated many libraries used by the editor which should be more performant.

## Foxhole Changes
- Added toggleable categories and a custom interval setting to the statistics panel.
- Added setting to hide stats for invisible layers when no layer is selected.
- Sub-Region maintenance supply modifiers have been removed entirely.
- Added custom tint / brightness options to images and game objects.
    - Brightness can be unlocked by enabling advanced settings and may negatively impact performance when applied to a large amount of objects (100+).
- Map Improvements:
    - Organized map options into separate categories with updated names.
    - Added buttons for toggling region names, voronoi cells, and borders.
    - Added Emplacement House (Mortar House) and Water Well icons.
    - Added faction-based circle indicators to Victory Bases.
    - Added setting to enable colored resource icons.
    - Fixed zooming when switching the background map color.
- Updated Toolbelt Panel:
    - Exchanged the old Toolbelt browser for the new Assets Browser.
    - Added the ability to bind community blueprints, selections, and tools to keys.
    - Added a new context menu button for changing settings and hiding the toolbelt.
- Line-of-Sight ranges are now enabled by default.
- Removed bunker destruction stats setting. (This setting is now always enabled)
- Removed bunker stats wet / dry button. (Wet & Dry stats are now always displayed)
- Removed Faction theming and added setting to prevent projects from selecting faction.
