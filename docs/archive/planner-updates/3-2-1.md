## General Changes
- Added ability to edit properties of multiple shapes (of the same type) at once.
- Added copy / paste style properties for shape objects.
- Added trackpad support for better navigation on laptops.
- Added pinch / drag support for mobile.
- Added smooth camera setting.
- Camera system replaced.
- Improved double click registration for hand tool.

## Foxhole Changes
- Added new "Icon" object to place down icons for items and structures from Foxhole.
- Added 171 items, weapons, and ammunition from Foxhole into new item categories.
- Added ship parts and rocket parts to the shippables category.
- Added new "Packaged" option for shippables to display their packaged texture.
- Added shift-clicking building-related assets to place their icon on the board.
- Fixed camera zoom being uncapped after disabling the map.
- Fixed support for tint / brightness on packaged items.
