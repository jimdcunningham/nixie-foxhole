## General Changes
- Added shift + left-click to zoom out with the hand tool.
- Fixed zoom buttons getting stuck when zooming out at certain zoom levels.

## Foxhole Changes
- Updated Foxhole recipes / data to the latest dev branch.
- Updated to latest Foxhole IMM version and updated base layers.
- Added shift + left-click for selecting unpiped trench networks.
- Added sub-cell lines and labels to grid for world map.
- Added toggleable dark map background in settings.
- Fixed hand tool going to incorrect position when clicking an icon.
- Adjusted Storm Cannon max range to 1000m.
- Updated pipe inputs for Metalworks Recycler and Rocket Platform.
