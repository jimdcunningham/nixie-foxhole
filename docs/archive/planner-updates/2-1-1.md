## General Changes
- Added logging in with Discord and Google.
- Reimplemented updates tab in the hub.
- Added board UI scale setting.
- Added toggleable panels for assets and layers to the sidebar.
- Updated header bar to be more compact.
- Added support for rendering markdown in the hub.
- Moved hub sidebar navigation to the top of the hub.
- Added setting for showing hub upon startup.
- Added fullscreen button to the hub.

## Foxhole Changes
- Added selectable icons for various containers and vehicles.
- Added inventory slots and render preview to hover tooltip for various vehicles.
- Added shift-click for toggling all other icons in map icon overlays.
- Added Binoculars tool, a variant of the line tool.
- Added Azimuth option to lines.
- Updated size of all regions to better match the in-game map.
- Moved Overlays panel to sidebar.
- Moved Offshore Platform from Harvesters to References.
- Removed map tab from the hub.
- Removed LOS for all spline / bezier objects.
- Fixed issue with switching shards not clearing out previous map instance.
- Fixed some vehicles / structures incorrectly consuming maintenance supplies.
- Fixed large and small trains being able to connect to each other.
- Fixed some z-fighting with icons and faction shading for the map.
