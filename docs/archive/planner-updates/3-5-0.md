## General Changes
- Added notifications dropdown panel.
- Added per-action keybind reset in Controls hub.
- Updated keybind settings to store bindings by action instead of by key.
- Updated brush tool to now show a brush-size/color preview before drawing.
- Updated brush stroke selection so strokes can be selected by clicking along the stroke path.
- Updated eraser behavior for brush strokes so it removes segments along the path.
- Fixed brush tool deleting strokes that were too small. (dots)
- Fixed eraser tool to only create history points when objects are deleted.
- Fixed board right-click menu on macOS.

## Foxhole Changes
- Added "Mark II Raidbreaker" and "Shatter Missile" to Bunker Destruction Stats.
- Added custom map mod .pak importer support.
- Updated icon for "Poseidon" Aircraft Carrier.
- Updated to the latest Improved Map Mod layers and base map variants by Rust.
- Updated power line behavior to stay connected when moving linked structures.
- Fixed Toolbelt item icons being placed as point objects instead of icon objects.
