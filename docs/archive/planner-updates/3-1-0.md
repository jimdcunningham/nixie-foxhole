## General Changes
- Added "Unlisted" privacy option to community blueprints.
- Pasted or dragged-in images will now always create new assets.
- Fixed assets creating duplicates if matching asset had an appended number.

## Foxhole Changes
- Imported new content from Foxhole Update 57.
- Added hammer repair rate to bunker health stats panel.
- Added setting to combine displayed resource icons for the stock network overlay.
- Items that require technology will no longer display when "Tier 1" is selected in Assets.
- Fixed incorrect tech values for various structures, items, and vehicles.
