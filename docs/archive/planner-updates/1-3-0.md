## Major Changes
- Added Region Selection (Map):
    - Select a region to be your project background.
    - Switch between Foxhole and BMM styled maps.
    - Crop a selection of the map with the new "Region Crop Tool"
    - Enable Shading, Topology, Road, Road Tiers, Rail, and RDZ Layers provided by BMM.
    - Enable the Grid layer to match that of the in-game map.

## Other Changes
- Added blueprint & dig site variants of Bunker, Trench, and Emplacement pieces.
- Added toggle for power / production stats per building.
- Added foundation requirements to building hover info.
- Added setting for toggling single selection stats.
- Added new hotkeys for Map (M) and Blueprinting selections (B).
- Added Observation Tower reference and Abisme AT-99 Tank Mine.
- Added selected tool information to footer.
- Added new "About" page to the Planner Hub.
- Layers menu has been updated to accomodate the new map.
- Gate T1 no longer blocks LOS.
- Updated hitbox of AT Gun Garrison (Tier 3).
- Fixed issue with loading the same project. (Chromium)
