## General Changes
- Added "Favorites" category to the Assets browser.
- Added "Report Content" option for flagging Blueprints.
- Added "Last Updated" date to Blueprint listings.
- Added filtering options to Blueprints hub. (ie. Title, Author, Date, Sorting)
- Added "Show Unmoderated Content" setting to the Blueprints hub filter.
- Updated various navigation buttons in the Blueprints hub.
    - "Uploads" and "Subscriptions" can now be found in the "Directory" menu button.
    - "Return" button now uses proper window navigation to keep a directory selected.
- Updated Blueprint searching to simultaneously search titles and authors.
- Fixed "Rename Layer" menu option not keeping names.
- Fixed logging out of accounts.
- Fixed position properties not allowing negative values.
- Fixed scale and position properties for repeating images.
- Fixed incorrect ordering of some Blueprint listings.
- Fixed Blueprint pages ignoring line breaks.
- Possible fix for error(s) while clearing the board of old objects.
- Pointer selection now uses screen coordinates instead of world coordinates.
